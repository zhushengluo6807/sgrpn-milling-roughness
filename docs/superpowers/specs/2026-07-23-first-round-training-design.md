# 首轮网络训练设计

## 1. 目标与范围

首轮工作先建立可复现、无同源泄漏的训练基础设施，并复现工艺参数基线。此阶段不训练 CNN、TCN 或弱物理残差网络；只有在数据映射、分组划分和基线指标通过验收后，才增加振动分支。

首轮交付包括：

- 独立 Python 虚拟环境及锁定后的依赖清单；
- 586 个片段的统一数据清单；
- 212 个原始实验组的严格分组交叉验证；
- 均值、工艺参数和几何先验基线；
- 可复现的指标、逐折预测和数据审计结果；
- 为后续 1D-CNN/CNN-TCN 复用的项目结构。

## 2. 环境设计

- 基础解释器：`python`（Python 3.12）
- 虚拟环境：`<repo>\.venv`
- GPU：NVIDIA GeForce RTX 4060 Laptop GPU，8 GB 显存
- PyTorch：稳定版 CUDA 12.8 构建
- 基础依赖：PyTorch、NumPy、pandas、SciPy、scikit-learn、openpyxl
- 实验依赖：Matplotlib、Seaborn、tqdm、PyYAML、TensorBoard、joblib
- 测试依赖：pytest

不安装 torchvision、torchaudio、Jupyter 和 XGBoost。首轮任务不需要这些组件。安装完成后生成锁定版本清单，并验证 `torch.cuda.is_available()`、GPU名称及一次GPU张量运算。

## 3. 数据来源

### 3.1 振动数据

固定使用：

`<repo>\切削实验\预处理并切分后实验数据_不扩展剔除\segments`

CSV 应包含 `Time_s、Ch9_g、Ch10_g、Ch11_g`。首轮基线不读取完整振动数组，但会验证标签表中的每个片段能唯一解析到一个CSV，为下一阶段做好准备。

### 3.2 标签

标签来源：

`<repo>\切削实验\粗糙度测量记录表_按切分片段.xlsx`

关键字段为版本、执行顺序、原始实验组、切分数、区域编号、片段时长、三次Ra测量值及Ra平均值。

### 3.3 工艺参数

- v3：`<repo>\切削实验\实验记录表_改进版_v3.xlsx`
- v4：`<repo>\切削实验\实验记录表_改进版_v4.xlsx`

使用 `(版本, 执行顺序)` 作为连接键：

- `n`：实验记录表 G 列“转速 (rpm)”；
- `fz`：实验记录表 H 列“进给 (mm/z)”；
- `ap`：实验记录表 J 列“切深 (mm)”。

同一原始实验的全部片段共享 `n、fz、ap`，但保留各片段独立的Ra标签。不得根据文件名、振动频谱或粗糙度值反推工艺参数。

## 4. 统一数据清单

构建一个只读派生清单，每行对应一个片段，至少包含：

- `sample_id`：版本、执行顺序和区域编号组成的唯一标识；
- `group_id`：版本和执行顺序组成的原始实验组标识；
- `version、execution_order、region_index、split_count`；
- `signal_path、duration_s`；
- `ra_1、ra_2、ra_3、ra_mean、ra_std、ra_range`；
- `n_rpm、fz_mm_per_tooth、ap_mm`；
- `ra_geo_um = fz^2 / (32R)`，其中刀具半径 `R=5 mm`，并完成毫米到微米的单位换算。

清单构建必须满足：586行、212个唯一组、`sample_id` 无重复、标签和工艺参数无缺失、586个CSV全部存在。任一条件失败即停止训练。

## 5. 数据划分与权重

所有划分以 `group_id` 为最小单位。同一加工实验的1至3个片段不得跨训练折和验证折。

首轮采用5折分组交叉验证，并保存每一折的组清单。划分种子固定为 `20260723`，后续所有模型复用完全相同的折，禁止各模型重新随机划分。

每个片段的评估权重为：

`w_ij = 1 / K_i`

其中 `K_i` 是第 i 次加工的片段数，使每次原始加工在损失和指标中具有相同总权重。结果同时报告普通片段级指标和组均衡指标，组均衡指标作为主要结果。

## 6. 首轮模型

依次训练：

1. `DummyRegressor`：训练折加权均值；
2. 线性工艺参数模型：标准化后的 `n、fz、ap`；
3. 二阶工艺参数模型：`n、fz、ap` 的二阶项与交互项，使用带正则化的Ridge；
4. 非线性工艺参数模型：`HistGradientBoostingRegressor`，使用 `sample_weight`；
5. 可校准几何基线：仅使用 `Ra_geo` 学习尺度和偏置；
6. 工艺参数加几何先验模型：检验 `Ra_geo` 是否在 `n、fz、ap` 之外提供增量。

所有标准化、特征扩展和模型拟合必须位于交叉验证管道内部，不能在全量数据上预先拟合。

## 7. 指标与输出

每个模型报告：

- MAE；
- RMSE；
- R²；
- 每折指标的均值和标准差；
- 组均衡MAE、RMSE和R²；
- 训练时间和推理时间。

保存：

- 数据审计 JSON；
- 固定折定义；
- 每个片段的折外预测；
- 逐折指标 CSV；
- 汇总指标 JSON/CSV；
- 预测值与真实值散点图、残差图；
- 运行配置、随机种子和依赖版本。

## 8. 验收标准

首轮通过必须同时满足：

1. 环境可复现，PyTorch能够识别RTX 4060；
2. 清单为586行、212组，全部工艺参数和CSV路径匹配；
3. 任一折中训练组与验证组交集为空；
4. 全部片段恰好获得一次折外预测；
5. 指标计算无NaN、Inf或数据泄漏；
6. 工艺参数模型显著优于均值基线；
7. 工艺参数最佳模型预期落在 `MAE 0.10–0.12 μm、R² 0.78–0.85` 的合理复现区间。

第7项是诊断区间而不是人为调参目标。若超出范围，优先检查折划分、样本权重、版本映射和指标定义，不通过改变划分追求历史数值。

## 9. 项目边界

首轮不包含：

- 原始振动的深度网络训练；
- CNN、TCN、Transformer或液态神经网络；
- 未经FRF标定的加速度二次积分物理约束；
- 超参数大规模搜索；
- 随机片段或窗口级训练测试划分。

首轮验收后，下一阶段复用同一清单和折定义，实现固定1秒窗口的纯振动轻量1D-CNN。
