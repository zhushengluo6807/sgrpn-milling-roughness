# 表面粗糙度物理—数据融合方案C设计

## 1. 目标

本项目以10 mm三刃立铣刀全槽铣铝块实验为对象，建立能够利用工艺参数和三向主轴振动预测表面粗糙度Ra的可复现模型。研究不只追求预测精度，还必须回答：

1. 仅使用工艺参数可以达到什么预测水平；
2. 振动信号在工艺参数之外是否提供稳定增量；
3. 简化物理先验能否提高可解释性、稳定性或泛化能力。

最终推荐模型采用物理—数据融合结构：

`Ra_pred = Ra_base + Delta_Ra_network`

其中`Ra_base`可以是简化物理模型，也可以是已验证的二次工艺参数模型；神经网络只学习基线尚未解释的粗糙度残差。

## 2. 范围和边界

### 2.1 本方案包含

- 固定、无泄漏的数据清单和5折分组交叉验证；
- 工艺参数与理想几何粗糙度基线；
- 三向振动信号的数据加载、窗口化、训练折内标准化和质量审计；
- 从实测加速度构造简化振动物理量；
- 纯振动轻量1D-CNN及1D-CNN+TCN；
- 工艺参数与CNN-TCN振动特征融合网络；
- 物理或工艺基线上的CNN-TCN残差网络；
- 同折、同指标、同权重的消融与稳定性评估；
- 可复现配置、折外预测、模型权重、图表和推理入口。

### 2.2 本方案暂不包含

- 由切削力闭环求解振动的完整`M/C/K`动力学模型；
- 未经实测FRF标定的主轴测点到刀尖TCP严格位移转换；
- 未经测力仪试验辨识的六个切削力系数；
- 缺少编码器时的严格逐齿相位与再生时滞求解；
- 未测量刀具跳动时的逐齿跳动补偿；
- Transformer、超大网络或大规模超参数搜索。

完整动力学模型保留为后续扩展，不作为当前方案C的前置条件。

## 3. 已确认的数据事实

- 样本片段：586个；
- 原始加工实验组：212组；
- 振动通道：`Ch9_g、Ch10_g、Ch11_g`；
- `Ch11_g`已确认是Z方向；
- `Ch9_g、Ch10_g`为两个横向通道，X/Y对应关系后续确认；
- 进给方向后续可以提供；
- 时间列：`Time_s`；
- 全部CSV采样率：25,600 Hz；
- 单片段长度：25,600至170,667点；
- 单片段时长：约1.00至6.67秒；
- 工艺参数：`n、fz、ap`；
- 刀具已知信息：直径10 mm、半径5 mm、三刃；
- 材料：Al 6061-T6；
- 铣削方式：逆铣；
- 冷却状态：实验要求使用冷却液；
- 粗糙度标签：每片段三次Ra测量值、均值、标准差和极差；
- 粗糙度测量表面：已确认是槽底；
- 粗糙度测量为接触式轮廓仪，已记录取样长度0.8 mm和进给位置X=45/75/105 mm；
- 测量空间位置按进给方向分区，并与区域片段一一对应；
- 固定外层划分：按原始实验组进行5折交叉验证；
- 固定随机种子：`20260723`；
- 片段权重：`1 / split_count`，保证每次原始加工总权重相同。

### 3.1 已执行的信号预处理

当前586个CSV不是原始采集信号，而是已经完成以下处理的正式建模数据：

1. 人工截取稳定切削区间，排除进刀、出刀、抬刀和主轴非稳定阶段；
2. 文件级检查通道完整性、有限数值、时间轴、采样间隔、常数通道和饱和削顶；
3. 每个通道减去该通道中位数，去除直流偏置；
4. 采用FFT方式执行20-10000 Hz带通滤波；
5. 不删除局部强振动窗口，不删除或拼接采样点；
6. 不重建时间轴；
7. 根据原时间轴和加工空间位置切成一至三个区域；
8. 每个区域匹配该区域独立测得的Ra标签。

因此，后续网络输入不得再次执行同一套20-10000 Hz带通和中位数去偏置。程序只做审计和训练折内幅值标准化，避免重复滤波改变信号。

实际转速范围为4000-8500 rpm，对应主轴转频66.7-141.7 Hz，三刃齿通过频率200-425 Hz。预处理依据文档中出现过58.3-91.7 Hz和175-275 Hz的旧范围，正式方案以实际工艺记录计算结果为准。

## 4. 总体架构

### 4.1 工艺基线分支

输入：

- 主轴转速`n`；
- 每齿进给量`fz`；
- 轴向切深`ap`。

该分支提供所有后续模型必须超过的基准。

### 4.2 简化物理分支

方案C使用三个层次的物理基准，逐级增加信息，但不冒充完整动力学模型。

#### 历史对照P0：侧壁几何公式

`Ra_geo_sidewall_proxy = fz^2 / (32R)`

该公式对应立铣刀侧铣时沿进给方向的理想残留齿痕近似。当前粗糙度测量对象已经确认是槽底，因此它不再作为方案C的槽底物理基准，只保留为历史对照和`fz^2`代理，用于解释首轮结果。后续代码应将当前`ra_geo_um`重命名为`ra_geo_sidewall_proxy_um`，避免物理含义混淆。

平头立铣刀槽底由端刃扫掠形成。若没有端刃有效生成半径、刀尖圆角、端刃轴向高低差、刀具倾斜和轴向跳动，不能把刀具整体半径`R=5 mm`代入同一公式构造槽底几何粗糙度。

#### 基准P1：工艺参数经验基准

使用当前已完成的二次工艺参数模型：

`Ra_process = f(n, fz, ap)`

作用：提供当前最强可复现对照，也是残差网络的一个基线锚点。该模型不是严格物理模型，但能够吸收切深和工艺交互带来的系统差异。

#### 基准P2：槽底实测振动物理代理

输入已经预处理的三向加速度，执行：

1. 确认`_g`数值的标定含义并换算为`m/s^2`；
2. 复核已有20-10000 Hz带通，不重复滤波；
3. 在频域内使用`X(f) = -A(f)/(2*pi*f)^2`计算带限位移代理，并统一换算为μm；
4. 使用已确认的`Ch11_g`构造槽底法向Z位移代理；
5. 单独构造两个横向候选位移代理和横向合成量，作为刀具侧向运动的辅助信息；
6. 计算各方向的`Ra_vib_proxy`、RMS位移、峰峰值位移和频带能量；
7. 以Z向位移代理为主，与工艺基线组合形成训练折内校准槽底物理代理。

在没有主轴测点到刀尖TCP传递函数时，上述结果必须称为“带限位移代理”，不能称为真实刀尖TCP位移。

槽底主物理代理形式：

`Ra_bottom_physical_cal = b0 + b1 * Ra_process + b2 * Ra_vib_Z + b3 * E_Z_TPF + b4 * E_Z_HF`

其中：

- `Ra_process`是当前二次工艺基线；
- `Ra_vib_Z`是Z向带限位移粗糙度代理；
- `E_Z_TPF`是Z向齿通过频率及邻域能量；
- `E_Z_HF`是Z向高频冲击能量占比。

所有校准系数只在当前训练折拟合。测试折不得参与尺度校准。横向A/B不直接解释为槽底法向位移，只作为辅助特征和消融项。

同时报告不含振动的`Ra_process`和仅增加Z向代理的模型，明确测量振动带来的增量。由于没有主轴测点到刀尖TCP传递函数，`Ra_vib_Z`仍然是主轴测点代理，不是真实刀尖轴向位移。

#### 非主线敏感性基准

已有资料提出过考虑静态让刀和径向跳动的表面生成模型。但当前没有实测跳动、等效刚度和切削力系数，因此该模型不作为方案C主物理基准。若论文需要，可在附录中对`e=0、5、10、15、20 μm`做敏感性分析，但不得将最优假设值解释为真实跳动。

### 4.3 纯振动分支

每个空间片段先拆成覆盖完整片段的1秒窗口，再以“片段窗口包”输入网络。网络只在片段级输出一个Ra，避免把同一标签的多个窗口伪装成独立样本。

轻量1D-CNN基线：

`3 x 25,600 -> 多尺度卷积 -> 残差卷积块 -> 全局池化 -> Ra`

推荐第一版卷积编码器：

1. `Conv1d(3,16,kernel=31,stride=4)`；
2. GroupNorm、GELU；
3. `Conv1d(16,32,kernel=15,stride=4)`；
4. GroupNorm、GELU；
5. `Conv1d(32,64,kernel=9,stride=2)`；
6. 全局平均池化与全局最大池化；
7. 投影为32维振动嵌入。

使用GroupNorm而不是依赖大批量统计的BatchNorm，以适应小样本和小批量训练。

CNN-TCN增强模型：

`3 x 25,600 -> 步长卷积CNN -> TCN膨胀残差块 -> 全局池化 -> Ra`

TCN第一版：

- 通道数64；
- 卷积核3；
- 膨胀率`1、2、4、8`；
- 每层使用残差连接、GroupNorm、GELU和Dropout 0.2；
- TCN只处理CNN降采样后的短序列，不直接处理原始25,600点；
- 片段内多个窗口的嵌入采用掩码均值池化；
- 第一版不使用注意力池化，降低过拟合风险。

轻量1D-CNN参数量控制在100万以内，CNN-TCN控制在200万以内。

#### 人工时频与物理特征

除深度特征外，保留一条可解释特征分支：

- 时域：RMS、标准差、峰峰值、峭度、偏度、峰值因子；
- 频域：名义主轴转频能量、齿通过频率能量、2至4倍频能量、高频能量占比、频谱质心；
- 物理代理：各方向位移RMS、`Ra_vib_proxy`、横向合成量；
- 工艺：`n、fz、ap、Ra_process`；
- 历史诊断：`Ra_geo_sidewall_proxy`只用于与首轮结果对照，不进入槽底最终物理主模型。

人工特征和标准化参数必须在训练折内确定。名义转频和齿通过频率由记录转速计算，不声称是真实瞬时阶次。

由于目标是槽底Ra，固定增加三组通道消融：

1. 仅Z向`Ch11_g`；
2. 仅横向`Ch9_g+Ch10_g`；
3. 三向`Ch9_g+Ch10_g+Ch11_g`。

Z向模型验证槽底法向振动的直接价值；横向模型检验侧向刀具运动是否通过载荷、倾斜或耦合间接影响槽底；三向模型作为最终性能候选。

### 4.4 工艺—振动融合分支

- CNN-TCN振动分支输出低维振动嵌入；
- 工艺分支使用小型MLP编码`n、fz、ap`；
- 可解释特征分支编码人工时频和物理代理特征；
- 三个嵌入拼接后预测Ra。

该模型用于判断振动信号是否在工艺参数之外提供增量。

### 4.5 残差融合分支

候选一：

`Ra_pred = Ra_bottom_physical_cal + Delta_Ra_CNN_TCN`

候选二：

`Ra_pred = Ra_quadratic_process + Delta_Ra_CNN_TCN`

最终模型由固定外层折的折外结果决定，不根据单次训练集表现选择。

#### 门控残差

最终候选增加一个小型门控网络：

`gate_inputs -> Linear(16) -> GELU -> Linear(1) -> Sigmoid`

门控输入包含`n、fz、ap、Ra_base、振动RMS、齿通过频率能量和高频能量占比`，输出`gate`位于0到1之间：

`Ra_pred = Ra_base + gate * Delta_Ra_CNN_TCN`

作用：在物理或工艺基准已经足够的稳定工况下抑制不必要的网络修正，在振动异常增强或大负载工况下允许更强残差补偿。门控模型必须与无门控残差模型进行消融比较。

### 4.6 固定模型对照矩阵

| 编号 | 模型 | 输入 | 作用 |
|---|---|---|---|
| M0 | 均值基线 | 无有效特征 | 确认模型至少优于常数预测 |
| M1 | 二次工艺模型 | `n、fz、ap` | 当前最强经验基线 |
| M2 | 历史侧壁几何公式 | `Ra_geo_sidewall_proxy` | 保留首轮对照，但不作为槽底物理模型 |
| M3 | 槽底振动物理代理 | `Ra_process、Ra_vib_Z、Z向频带能量` | 检查槽底法向振动代理是否具有独立解释力 |
| N1 | 轻量1D-CNN | 三向时域振动 | 检查局部波形的预测价值 |
| N2 | CNN-TCN | 三向时域振动 | 检查跨局部窗口的时序增量 |
| N3 | 人工特征模型 | 时频、物理代理、工艺特征 | 提供可解释的数据驱动对照 |
| N4 | 工艺+CNN-TCN | `n、fz、ap`与深度振动特征 | 判断振动在工艺基线之外的增量 |
| N5 | 工艺残差CNN-TCN | `Ra_process + Delta` | 让网络只学习工艺模型残差 |
| N6 | 槽底物理残差CNN-TCN | `Ra_bottom_physical_cal + Delta` | 让网络只学习槽底物理代理残差 |
| N7 | 门控槽底物理残差CNN-TCN | `Ra_bottom_physical_cal + gate * Delta` | 评估自适应残差强度是否更稳健 |

模型按M0至N7逐步增加复杂度。只有前一层对照稳定后才训练后一层，避免无法判断性能提升来自哪一部分。

## 5. 固定的数据与训练协议

### 5.1 外层测试

- 复用当前固定的5折`group_id`划分；
- 同一原始加工实验的所有片段和窗口必须在同一折；
- 外层测试折不得参与标准化、滤波参数学习、早停或模型选择；
- 所有候选模型使用完全相同的外层折。
- 残差网络训练样本所使用的`Ra_process`和`Ra_bottom_physical_cal`必须来自外层训练数据内部的交叉拟合预测，不能使用对同一样本直接拟合后再预测的结果；
- 外层测试折的基线预测由完整外层训练折拟合后生成。

### 5.2 窗口规则

- 窗口长度：1秒，即25,600点；
- 第一版步长：1秒，无重叠；
- 每个片段至少保留一个完整窗口；
- 若片段末端存在不足1秒的余量，再增加一个“以片段末端对齐”的1秒窗口，覆盖剩余空间区域；
- 末端窗口可以与前一窗口部分重叠，但不得跨越片段边界；
- 所有窗口先编码，再在片段内做掩码均值池化；
- 每个片段只产生一个损失和一个Ra预测；
- 片段损失权重保持为`1 / split_count`；
- 不把窗口数计入独立样本数，独立样本仍为212组、监督片段仍为586个。

### 5.3 预处理规则

- 原始加速度值保持可追溯；
- 当前输入CSV已经完成中位数去偏置和20-10000 Hz FFT带通；
- 不对正式输入重复执行同一滤波；
- 单位确认、物理量换算和训练标准化分别实现，不覆盖输入数据；
- 神经网络标准化统计量只在当前训练折计算；
- 采用训练折全局每通道尺度进行标准化，不做逐窗口单位方差归一化，以免抹去与粗糙度有关的绝对振幅；
- 物理积分使用当前20-10000 Hz有效信号，但必须根据传感器有效频带做一致性复核；
- 不允许使用测试折Ra选择滤波频带；
- 停机、主轴空转和空走刀数据如能补充，用于背景诊断、阶次对照和消融，不直接进行非同步时域波形相减。

### 5.4 神经网络训练

- 外层5折固定；
- 每个外层训练折内部按`group_id`划分训练组和早停验证组；
- 使用加权MAE或Huber损失；
- 优先使用AdamW，初始学习率`1e-3`、权重衰减`1e-4`；
- 最多200个epoch，早停耐心20个epoch；
- 使用训练折内验证MAE进行早停和学习率调整；
- 至少运行三个固定随机种子：`20260723、20260724、20260725`；
- 保存每折最佳权重、训练日志和预测；
- 不进行大规模自动超参数搜索。

## 6. 评价标准

### 6.1 主指标

- 组均衡加权MAE。

### 6.2 辅助指标

- 组均衡加权RMSE；
- 组均衡加权R²；
- 普通片段级MAE、RMSE和R²；
- 每折结果；
- 三随机种子均值和标准差；
- 组级Bootstrap置信区间；
- 训练时间和推理时间。

### 6.3 振动增量判据

当前最强基准是二次工艺参数模型：

- 加权MAE：0.1046165 μm；
- 加权RMSE：0.1410125 μm；
- 加权R²：0.8140201。

认为振动提供可靠增量，至少应同时满足：

1. 加权MAE相对改善不低于5%；
2. 至少4个外层折优于二次工艺参数基线；
3. 多个随机种子方向一致；
4. 改善不是由极少数异常组主导；
5. 数据划分、权重和评价口径保持不变。

未达到判据时仍保留结果，并得出“当前振动信息未提供稳定增量”的结论，不修改测试折追求更好数字。

### 8.3 已确认无法提供信息的处理方式

#### 无主轴编码器或转速脉冲

- 使用实验记录中的名义转速计算主轴转频`f_rot = n / 60`；
- 使用三刃刀具计算齿通过频率`f_tpf = 3n / 60`；
- 使用`T = 60 / (3n)`近似齿间周期；
- 允许进行基于名义转速的近似阶次和频带分析；
- 不进行严格相位同步平均、真实阶次跟踪或逐齿相位重建；
- CNN和CNN-TCN直接使用时间序列，不依赖编码器信号；
- 结果中明确标注“名义转速近似”，不声称获得真实瞬时主轴相位。

#### 无刀具或刀柄跳动记录

- 简化物理模型中不显式加入逐齿跳动项`e_j`；
- 不把一阶转频、齿间幅值差直接解释为已测量跳动；
- 可能存在的跳动、磨损和装夹偏心统一作为未观测扰动；
- 由融合或残差网络学习这些未建模因素对Ra的统计贡献；
- 最终报告将“无法分离跳动贡献”列为模型限制。
