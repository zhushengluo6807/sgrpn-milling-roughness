# SGRPN：选择性门控残差概率网络设计规格

**日期：** 2026-08-21  
**状态：** 用户已确认书面规格，进入实施计划阶段  
**研究对象：** 铣削加工表面粗糙度 Ra 预测  
**数据边界：** 仅使用现有实验数据，不追加加工、空转、停机或重复测量实验

## 1. 研究目标

本研究拟回答：

> 当工艺参数已经能够较准确地预测表面粗糙度，而振动信号存在明显域偏移和不稳定增量时，神经网络能否学习“何时使用振动修正、何时退回工艺基线”，并在严格分组验证下减少传感器融合造成的负迁移？

拟构建 **Selective Gated Residual Probabilistic Network（SGRPN，选择性门控残差概率网络）**。模型以工艺参数神经网络为稳定专家，以阶次谱卷积网络学习工艺专家未解释的残差，再由可信门控选择性开启振动修正。只有均值预测阶段通过预注册门槛后，才扩展重复测量感知的概率头和分组共形区间。

本方向的核心贡献不是提出更大的 CNN、Transformer 或 PINN，而是：

1. 面向弱增量、易负迁移的振动信息设计安全回退式神经融合；
2. 使用外层训练集内部交叉拟合残差，避免振动支路学习工艺模型的训练内误差；
3. 在独立加工组层面评估平均精度、负迁移和预测区间；
4. 对三次 Ra 读数进行重复测量感知建模，同时严格限制不确定性的解释范围。

## 2. 数据事实与研究边界

现有数据包括 212 个独立 `group_id` 加工运行、586 个区域区段和 189/200 个工艺参数组合。每个区域有三次 Ra 读数，振动采样率为 25.6 kHz，通道为 Ch9、Ch10 和 Ch11，其中 Ch11 可确认是 Z 向，Ch9/Ch10 的水平轴对应关系不能可靠确定。

前期严格分组验证表明：

- 二次工艺岭回归已达到约 0.144 μm RMSE 和 0.823 的 \(R^2\)；
- 单独使用紧凑振动特征的 \(R^2\) 约为 0.182；
- 工艺与振动直接融合可能劣于工艺基线；
- 两阶段工艺加残差信号仅获得约 1% 的 RMSE 改善；
- v3 与 v4 使用互不重叠的转速网格，版本与转速完全混杂。

因此，本研究遵守以下边界：

- 不把 v3/v4 差异解释为独立的批次效应或版本效应；
- v3/v4 仅用于复合域压力测试，不作为因果域适配证据；
- `version` 不进入模型输入，只用于分层误差诊断；
- 三次 Ra 读数不支持完整 Gauge R&R，不宣称分离了仪器、操作者和过程方差；
- Ch9/Ch10 不赋予确定的 X/Y 物理方向名称；
- 现有 `outputs/scheme1/` 和 `outputs/scheme1_physics/` 全部只读；
- 正式结论只依据外层 OOF/测试预测，不依据训练集拟合结果。

## 4. 输入与预处理

### 4.1 工艺输入

基础工艺量为转速 \(n\)、每齿进给量 \(f_z\) 和切深 \(a_p\)。Process-MLP 输入固定为 9 维：

\[
[n,f_z,a_p,n^2,f_z^2,a_p^2,nf_z,na_p,f_za_p].
\]

每个外层折和内层折的标准化器只能在对应训练索引上拟合。

### 4.2 区段时长

所有用于时间归一化和窗口划分的区段时长统一重算为：

\[
t=\frac{N_{rows}}{25600}.
\]

原始时长字段保留用于审计，不回写源数据。若重算值与元数据相差超过 1 ms，记录警告和差异；训练仍使用重算值。

### 4.3 阶次谱

每个有效 1 秒窗口包含 25,600 点。对各通道去均值、加 Hann 窗并计算单边功率谱，然后使用主轴转频 \(n/60\) 将频率轴转换为阶次轴：

\[
o=\frac{f}{n/60}.
\]

将 `log1p(power)` 线性插值到固定的 0–90 阶、步长 0.25 的 361 点网格。该上限在当前最高转速 8,500 rpm 下仍低于奈奎斯特阶次。网格、窗函数和插值规则在所有折保持一致，不根据外层测试标签调整。

各通道阶次谱使用当前训练折统计量标准化。区域内多个窗口经共享 CNN 编码后，以 masked mean 聚合为区域级振动表示。没有任何有效窗口的区域直接报错，不以全零信号静默替代。

### 4.4 水平通道不确定性

训练时以 0.5 概率交换 Ch9 与 Ch10。推理时分别计算原顺序和交换顺序的预测并取平均。Z 向 Ch11 保持不变。所有水平通道质量摘要使用对称聚合，避免在门控中重新引入伪方向。

### 4.5 信号质量输入

门控使用小规模、确定性的质量摘要：水平通道 log-RMS 的均值与最大值、水平谱熵的均值与最大值、Z 向 log-RMS、Z 向谱熵和有效窗口比例，共 7 维。质量特征的标准化同样仅使用当前训练折。

## 5. 模型架构

### 5.1 工艺专家 P1

Process-MLP 结构固定为：

```text
9
→ Linear(32) + ReLU + Dropout(0.10)
→ Linear(16) + ReLU
→ Linear(1)
→ μ_process
```

它既是独立对照模型，也是融合模型的安全回退基线。

### 5.2 振动专家

Residual-CNN 对每个窗口的三通道阶次谱进行编码：

```text
Conv1d(3, 16, kernel=7, stride=2) + BatchNorm + ReLU
Conv1d(16, 32, kernel=5, stride=2) + BatchNorm + ReLU
Conv1d(32, 64, kernel=3, stride=2) + BatchNorm + ReLU
AdaptiveAvgPool1d(1)
→ 64维窗口表示
→ 区域 masked mean
→ Linear(64, 32) + ReLU + Dropout(0.10)
→ Linear(32, 1)
→ Δ_vibration
```

该分支不直接拟合 Ra，而是学习外层训练集内部的交叉拟合工艺残差：

\[
r_{OOF}=\bar y-\mu_{process,OOF}.
\]

### 5.3 可信门控 G1

门控输入为 9 维工艺特征、64 维振动表示和 7 维质量摘要：

```text
80
→ Linear(16) + ReLU
→ Linear(1) + Sigmoid
→ g ∈ [0,1]
```

最终均值预测为：

\[
\hat y=\mu_{process}+g\Delta_{vibration}.
\]

当 \(g\to0\) 时退回工艺专家；当 \(g\to1\) 时使用完整振动修正。门控值只解释为模型内部的修正开启程度，不解释为真实物理可靠性概率。

## 6. 阶段 A：最小可行性实验

### 6.1 外层评估与种子

- 使用现有固定 5 折 `group_id` 外层划分；
- 阶段 A 只使用随机种子 `20260723`；
- 外层测试折只在模型和训练选择全部完成后预测一次；
- 同一 `group_id` 不得跨训练、验证、测试或共形校准集合。

### 6.2 工艺 OOF 残差

对每个外层训练集执行固定 4 折内层 Group CV：

1. 每个内层模型只拟合其内层训练组的标准化器；
2. 预测对应内层验证组，拼成完整的外层训练 OOF 工艺预测；
3. 用 OOF 预测计算振动专家的残差目标；
4. 最终 Process-MLP 在完整外层训练集上重训，用于外层测试预测。

P1、Residual-CNN 和 Trust-Gate 均使用同一套 4 折内层分组验证确定训练轮数。每个组件最终在其可用的完整外层训练数据上重训，轮数取该组件四个内层最佳轮数的中位数；训练下游组件时，上游组件按本规格冻结。外层训练组不被永久留作验证集。

### 6.3 分阶段训练

每个外层折按以下顺序执行：

1. 训练 P1，并生成无泄漏的工艺 OOF 残差；
2. 使用 OOF 残差训练 Residual-CNN；
3. 冻结 P1 与 Residual-CNN 的全部参数；
4. 只训练 Trust-Gate；
5. 阶段 A 不进行联合微调。

冻结约束用于避免门控系数与残差幅值发生不可辨识的反向补偿。

### 6.4 损失和优化

所有可训练的均值预测模型采用区域加权 Huber 损失，\(\delta=0.10\) μm；下式中的两个收缩项仅用于 G1：

\[
L=L_{Huber}(\hat y,y)
+10^{-3}E[g^2]
+10^{-2}E[(g\Delta)^2].
\]

区域权重为 `1/split_count`。优化器统一为 AdamW：P1 和门控学习率 `1e-3`，Residual-CNN 学习率 `3e-4`，权重衰减 `1e-4`；最多 200 轮，早停耐心值 20。上述值在阶段 A 固定，不依据外层结果改变。

### 6.5 预注册对照矩阵

| 编号 | 模型 | 目的 |
|---|---|---|
| M0 | 现有二次岭回归 | 传统强基线，只读加载 |
| P1 | Process-MLP | 检查神经工艺专家是否可靠 |
| V1 | 阶次谱 CNN 直接预测 | 评估振动单模态能力 |
| F1 | 工艺特征与振动表示直接拼接 | 量化朴素融合负迁移 |
| R1 | \(P1+\Delta\) | 检查无门控残差融合 |
| G1 | \(P1+g\Delta\) | 完整 SGRPN 均值模型 |

V1、F1、R1 和 G1 使用相同的阶次谱、CNN 容量、外层折和样本权重。不得根据中间结果删除不利对照。

## 7. 阶段 A 指标与停止门槛

主指标为区域加权 MAE；辅助指标为加权 RMSE 和加权 \(R^2\)。同时报告每折结果、212 个 `group_id` 的配对比较和 10,000 次组级配对 Bootstrap 95% 区间。

“原始负迁移组”定义为该组相对 P1 的平均绝对误差增加大于 0；“实质性负迁移组”定义为增加超过 0.01 μm。二者均报告，进入阶段 B 的判定使用后者。

### 7.1 工艺专家可信度

P1 相对 M0 必须同时满足：

- 加权 MAE 恶化不超过 5%；
- 加权 \(R^2\) 下降不超过 0.02。

若未通过，先停止融合结论，原因记录为神经工艺专家不适合作为安全基线。

### 7.2 G1 非劣性

G1 相对 P1 必须满足：

- 加权 MAE 恶化不超过 1%；
- 加权 RMSE 恶化不超过 3%；
- 加权 \(R^2\) 不低于 P1。

### 7.3 进入阶段 B 的有效信号

在满足非劣性的前提下，以下两条至少满足一条：

1. G1 相对 P1 的加权 MAE 改善至少 1%，且至少 3/5 外层折改善；
2. G1 相比 F1 和 R1，实质性负迁移组比例均降低至少 10 个百分点。

若门控中位数低于 0.05、95 分位数低于 0.20，且没有精度或负迁移收益，停止阶段 B，结论为当前振动信号未提供可靠的条件增量信息。

门控塌缩本身不被隐藏；若其与无损回退同时出现，可作为“模型拒绝不可靠传感器信息”的描述性结果，但不能单独构成成功结论。

## 8. 阶段 B：重复测量感知概率模型

阶段 B 仅在阶段 A 通过后执行，并扩展到种子 `20260723`、`20260724`、`20260725`。每个种子重新训练均值模型，不从阶段 A 单种子结果选择有利初始化。

### 8.1 三次读数的使用

每个区域仍是一个样本，保留 \((y_{i1},y_{i2},y_{i3})\)，不拆成三个独立区域。均值模型以三次读数平均值为目标。概率损失对三个读数取平均后再施加区域权重，因此每个区域的总权重仍为 `1/split_count`。

### 8.2 方差头

冻结已训练的均值模型。方差头输入 9 维工艺特征、64 维振动表示、7 维质量摘要、门控值和振动修正绝对值，共 82 维：

```text
82
→ Linear(32) + ReLU
→ Linear(16) + ReLU
→ Linear(1)
→ softplus + 1e-4
→ σ
```

使用三次读数的平均高斯负对数似然训练。对照包括一个仅学习全局标量 \(\sigma\) 的同方差模型。

\(\sigma\) 只能解释为给定工艺和振动观测时，重复读数与未建模误差共同形成的条件预测离散度，不解释为仪器精度、纯测量误差或已分解的过程方差。

### 8.3 分组共形校准

在每个外层训练集内部生成均值和尺度的内层 OOF 预测，计算：

\[
s_{ij}=\frac{|y_{ij}-\mu_i|}{\sigma_i}.
\]

同一 `group_id` 内全部区域和重复读数取最大值，形成一个组级分数。对 \(m\) 个校准组使用有限样本修正分位位置 \(\lceil(m+1)(1-\alpha)\rceil/m\)，分别构造 90% 和 95% 区间：

\[
[\mu_i-q_\alpha\sigma_i,\mu_i+q_\alpha\sigma_i].
\]

主要覆盖声明是新 `group_id` 内全部现有类型区域与重复读数的同时覆盖。另行报告单次读数覆盖率，但不把相关区段当作独立校准样本。

### 8.4 概率指标

阶段 B 报告：

- Ra 均值的 MAE、RMSE 和 \(R^2\)；
- 高斯 NLL；
- 单次读数覆盖率；
- `group_id` 级同时覆盖率；
- 平均区间宽度；
- Winkler 区间评分；
- 原始概率区间与共形区间对比；
- 同方差与异方差消融。

若异方差头不能改善区间评分，或共形后区间失去实用宽度，则论文不强调异方差学习，只保留分组共形校准结果和限制说明。

## 9. 防泄漏和失败保护

程序必须在训练前和每折运行时断言：

1. 外层训练组与测试组无交集；
2. 内层训练组与验证组无交集；
3. 标准化、早停、残差目标和共形分位数均未读取外层测试标签；
4. 数据为三通道、采样率为 25.6 kHz，标签和工艺量有限；
5. 每个区域至少有一个有效窗口；
6. 最终 OOF 预测无缺失、无重复并覆盖所有目标区域；
7. Bootstrap 抽样单位为 `group_id`；
8. checkpoint 的折、种子、模型和配置指纹与当前任务一致。

每个外层折独立保存 checkpoint、训练历史和完成标记。中断后只恢复指纹完全一致的已完成折；配置或数据指纹变化时拒绝混用旧结果。

CUDA 不可用时允许回退 CPU，但必须记录设备。训练运行使用项目现有 `python`，不修改全局 Python，不自动安装依赖。

## 10. 输出与可复现性

阶段 A 和 B 分别写入独立目录。每次正式运行至少输出：

- `run_manifest.json`：配置、随机种子、数据指纹、环境与设备；
- 固定折和内层折定义；
- 每模型、每折、每种子的训练历史与 checkpoint；
- 区域级和组级 OOF 预测；
- 汇总指标、折级指标和对照差值；
- 10,000 次组级配对 Bootstrap；
- 原始与实质性负迁移统计；
- 门控总体分布及按 \(n\)、\(f_z\)、\(a_p\)、质量特征分层的分布；
- v3/v4 复合域压力测试结果及混杂声明；
- 预测—实测图、残差图、折稳定性图、门控热图；
- 阶段 B 的覆盖率—区间宽度图和区间评分表；
- 机器可读的逐条验收结论和停止原因。

所有图表必须能够从保存的 OOF 预测和配置重新生成，不依赖内存中的未保存状态。

## 11. 自动化测试

至少覆盖：

1. 已知正弦信号在阶次谱中产生正确阶次峰；
2. 0–90 阶网格长度固定为 361；
3. 水平通道交换后的推理平均预测保持不变；
4. 区段时长严格等于行数除以 25,600；
5. Process-MLP 输入恰为 9 维且标准化器只拟合训练索引；
6. OOF 残差只由未见过该组的 P1 模型产生；
7. \(g=0\) 时 G1 等于 P1，\(g=1\) 时等于 P1 加完整残差；
8. 冻结训练期间 P1 和 Residual-CNN 参数逐项不变；
9. 方差头输出始终为有限正值；
10. 三次读数平均后的区域总损失权重不变；
11. 共形校准每个 `group_id` 只贡献一个组级分数；
12. 外层测试标签不进入任何拟合或选择接口；
13. 合成小数据可跑通一个外层折和命令行入口；
14. M0 结果能够只读加载且旧输出内容不变化；
15. 验收器能输出通过、停止及每条机器可读原因。

正式训练前执行单元与集成测试；正式结果生成后再执行输出完整性和指纹验证。

## 12. 论文结论约束

- G1 优于 P1：可以表述振动提供了条件增量，但不证明具体物理机制；
- G1 均值不优于 P1、但显著降低 F1/R1 负迁移：可以表述选择性门控提高了融合安全性；
- 门控关闭且无稳定收益：结论为现有振动数据不足以支持可靠增量，不继续结果驱动调参；
- v3/v4 压力测试差异：只能归因于包含转速网格在内的复合域变化；
- 概率区间覆盖达标：只能在与现有独立加工组可交换的样本范围内解释；
- 三次重复读数不能支持 Gauge R&R 或方差来源分解；
- 不通过外层结果回改模型、门槛、阶次范围或对照矩阵；
- 所有失败和停止结果完整保留，不只报告有利种子或折。

## 13. 完成定义

本设计的实现完成需同时满足：

1. 阶段 A 六个模型按固定 5 折成功生成完整 OOF 结果；
2. 所有防泄漏、单元、集成和输出完整性测试通过；
3. 验收器按预注册门槛给出可复现的进入阶段 B 或停止结论；
4. 只有阶段 A 通过时才执行阶段 B；
5. 阶段 B 输出三种子概率预测、分组共形区间和消融结果；
6. 旧实验目录和正式结果未被修改；
7. 论文图表、指标表和限制说明均可从机器可读产物重建。
