# 槽底表面粗糙度预测双方案设计

日期：2026-07-27  
状态：已完成对话设计确认，等待书面规格复核  
适用项目：Al 6061-T6 全槽铣削三轴振动区域级表面粗糙度 `Ra` 预测

## 1. 设计目的

本规格将后续研究固定为两套可独立选择、共享评估底座的方案：

- **方案1：现有数据下的最小物理—数据融合路线。** 不补充新实验，使用现有586个区域片段和212组独立加工实验，处理端刃有效生成半径与横向通道方向未知的问题。
- **方案2：实测槽底几何与基准信号增强路线。** 补齐端刃几何、传感器和测量信息，并增加停机、主轴空转及相同NC路径空走刀信号，建立更可信的槽底物理代理。

用户后续会明确说“推进方案1”或“推进方案2”。未收到明确选择时，不开始对应方案的代码实现或模型训练。

## 2. 共同研究问题

两套方案均围绕同一个核心问题：

> 在严格按原始加工实验分组、防止同源片段和窗口泄漏的评估下，三轴振动能否解释工艺参数或槽底物理基线尚未解释的区域级Ra动态残差？

研究结论不得简化为“CNN或TCN能够预测粗糙度”。必须分别回答：

1. 工艺参数能达到什么水平；
2. 原始振动是否提供稳定增量；
3. TCN是否在CNN之外提供独立增量；
4. 工艺融合和残差结构是否有效；
5. 槽底几何与背景振动校正是否具有独立贡献；
6. 改善是否跨折、跨种子且不由少数异常组主导。

## 3. 共同数据与评估底座

### 3.1 固定数据

- 独立加工实验：212组；
- 区域级监督片段：586个；
- 每个片段具有独立Ra标签；
- 采样率：25,600 Hz；
- 振动通道：`Ch9_g`、`Ch10_g`、`Ch11_g`；
- `Ch11_g=Z`已确认；
- 工艺参数：`n`、`fz`、`ap`；
- 固定随机种子：`20260723`；
- 正式输入目录：`切削实验/预处理并切分后实验数据_不扩展剔除/segments`。

现有CSV已经完成：

1. 人工截取稳定切削段；
2. 每通道中位数去直流偏置；
3. 20–10000 Hz FFT带通；
4. 保留局部强振动；
5. 不删除或拼接采样点；
6. 保留原时间轴；
7. 按加工空间区域切分并匹配独立Ra标签。

后续不得重复执行相同带通和中位数去偏置。

### 3.2 固定无泄漏规则

- 复用现有固定5折；
- 以`group_id`为划分单位；
- 同一加工实验的所有片段和窗口不得跨折；
- 每个片段权重为`1/split_count`；
- 每个原始实验总权重为1；
- 标准化、特征筛选、`r_e`选择、X/Y映射选择、早停和模型选择只使用当前外层训练折；
- 残差网络训练样本的基线预测必须来自外层训练集内部交叉拟合；
- 外层测试折只用于一次最终评估。

### 3.3 固定窗口规则

- 窗口长度：1秒，即25,600点；
- 第一版步长：1秒，无重叠；
- 片段末端不足1秒时，增加一个末端对齐的1秒窗口；
- 窗口不得跨片段；
- 所有窗口先编码，再做片段内掩码均值池化；
- 每个片段只输出一个Ra和一个损失；
- 窗口不作为新的独立监督样本。

### 3.4 正式基线

当前正式最强基线为`quadratic_process`：

| 指标 | 数值 |
|---|---:|
| 组均衡加权MAE | 0.1046165 μm |
| 组均衡加权RMSE | 0.1410125 μm |
| 组均衡加权R² | 0.8140201 |

两套方案均复用同一折、权重和指标，与该基线做逐片段配对比较。

## 4. 共同网络主线

两套方案都保留以下固定路线：

```text
1D-CNN基线
    ↓
1D-CNN + TCN增强模型
    ↓
工艺参数 + CNN-TCN融合
    ↓
物理/工艺基线 + CNN-TCN残差模型
    ↓
门控残差候选
```

人工时频特征、槽底物理代理、X/Y映射和基准信号校正是解释性分支及消融，不取代上述网络主线。

### 4.1 第一版CNN

```text
3 → 16(k31,s4) → 32(k15,s4) → 64(k9,s2)
```

- GroupNorm；
- GELU；
- 全局平均池化与最大池化；
- 投影为32维振动嵌入；
- 参数量控制在100万以内。

### 4.2 第一版TCN

- 通道数64；
- 卷积核3；
- 膨胀率`1/2/4/8`；
- 残差连接；
- GroupNorm；
- GELU；
- Dropout 0.2；
- 只处理CNN降采样后的特征序列；
- CNN-TCN总参数量控制在200万以内。

### 4.3 训练协议

- 外层固定5折；
- 外层训练折内部按`group_id`划分训练和早停验证组；
- 使用加权MAE或Huber损失；
- AdamW，初始学习率`1e-3`、权重衰减`1e-4`；
- 最多200 epoch；
- 早停耐心20；
- 固定种子`20260723/20260724/20260725`；
- 保存每折、每种子最佳权重、日志和OOF预测；
- 不进行大规模自动超参数搜索。

## 5. 方案1：现有数据下的最小物理—数据融合

### 5.1 目标和边界

方案1不补充新实验，回答：

> 在端刃有效生成半径和横向通道方向均不确定的条件下，现有三轴振动能否稳定解释工艺参数尚未解释的Ra残差？

限制：

- `Ch11_g`固定为Z向；
- `Ch9_g/Ch10_g`建立两套X/Y假设；
- 传感器标定未确认时，位移量只作为相对代理，不换算为真实刀尖位移或微米；
- 未实测的`r_e`不得解释为真实刀具参数；
- 不使用刀具整体半径`R=5 mm`代替槽底有效生成半径。

### 5.2 横向通道双假设

- 假设A：`Ch9=X，Ch10=Y`；
- 假设B：`Ch9=Y，Ch10=X`。

两种假设使用完全相同的折、种子、模型和超参数。

选择规则：

1. 在每个外层训练折内部比较A和B；
2. 使用内层分组验证选择当前外层折的映射；
3. 锁定后评估外层测试折；
4. 汇总五折的嵌套选择结果。

如果同一映射在至少4/5折及三个随机种子中稳定占优，可称为“预测上更受支持的方向假设”，但不能视为传感器安装方向的直接测量证据。选择不稳定时，最终使用横向合成或通道对称表示。

### 5.3 槽底几何敏感性代理

存在端刃有效圆角或过渡半径时，槽底几何项为：

\[
Ra_{geo,bottom}(r_e)
=
\frac14
\left[
r_e-\sqrt{r_e^2-(f_z/2)^2}
\right]
\]

若使用毫米输入，结果乘以1000转换为微米，并要求：

\[
f_z\le 2r_e
\]

方案1预注册候选：

\[
r_e\in\{0.075,\ 0.10,\ 0.20,\ 0.40,\ 0.80\}\ \mathrm{mm}
\]

另设“无几何项”候选。所有候选只在外层训练折内部选择。

解释边界：

- 候选值只表示有效生成半径敏感性；
- 不报告为真实刀具圆角；
- 若不同折选择不一致，只报告有效尺度敏感性；
- 若几何项无稳定增量，最终模型自动删除该项。

### 5.4 最小物理与信号特征

Z向候选：

- RMS、标准差、峰峰值、峭度、峰值因子；
- 名义转频邻域能量；
- TPF及2–4倍频能量；
- 高频冲击能量占比；
- 频谱质心和频谱熵；
- 带限位移代理`D_Z`。

带限位移代理：

\[
D_Z\propto
\operatorname{RMS}
\left[
\mathcal F^{-1}
\left(
-\frac{A_Z(f)}{(2\pi f)^2}
\right)
\right]
\]

零频必须排除，结果必须通过有限值检查。单位未确认时只报告相对单位。

横向候选：

- 两个横向通道各自的时频特征；
- 与方向无关的横向合成量；
- A/B假设下的进给向和横向特征；
- 第一版不使用带符号相位，只使用幅值、能量和绝对谱量。

### 5.5 方案1模型矩阵

| 编号 | 模型 | 目的 |
|---|---|---|
| M0 | `quadratic_process` | 正式工艺基线 |
| P1 | 工艺＋Z向人工特征 | 检验最小Z向增量 |
| P2 | P1＋横向合成特征 | 检验横向整体信息 |
| P3A/B | P2＋方向专属特征 | 比较A/B坐标假设 |
| P4 | P1/P2＋槽底几何敏感性代理 | 检验`r_e`代理增量 |
| N1 | 纯振动轻量1D-CNN | 检验局部波形价值 |
| N2 | 纯振动CNN-TCN | 检验TCN独立增量 |
| N3 | 工艺参数＋CNN-TCN | 检验振动超越工艺参数的增量 |
| N4 | 工艺基线＋CNN-TCN残差 | 方案1核心候选 |
| N5 | 最小物理基线＋CNN-TCN残差 | 仅在P4有效时作为核心候选 |
| N6 | 门控残差模型 | 仅在普通残差有效时启用 |

通道消融：

- 仅Z向；
- 仅两个横向通道；
- 三向A/B映射；
- 横向合成或通道对称表示。

### 5.6 方案1阶段验收

| 比较 | 判定标准 |
|---|---|
| N1 vs 均值基线 | 明显优于均值且多数折方向一致 |
| N2 vs N1 | MAE改善≥2%，至少3/5折改善，种子平均方向一致 |
| N3 vs M0 | MAE改善≥3%，至少3/5折改善 |
| N4 vs M0 | MAE改善≥5%，至少4/5折改善，三个种子均改善 |
| N5 vs N4 | MAE进一步改善≥2%，至少3/5折改善 |
| N6 vs N5 | MAE进一步改善≥1%，且不增加明显折间波动 |

方案1结论分级：

- **未发现稳定增量：** N3/N4相对M0改善不足3%，或折和种子方向反复。
- **存在探索性增量：** 最佳模型改善≥3%，至少3/5折改善，三个种子的平均方向一致。
- **稳定有效：** 最佳模型改善≥5%，至少4/5折改善，三个种子分别均改善，组级Bootstrap 95%置信区间支持改善。

5%改善对应MAE低于约：

\[
0.1046165\times0.95=0.09939\ \mu m
\]

### 5.7 方案1停止与降级

- N2不能稳定优于N1：后续融合使用CNN，不强调TCN；
- N3和N4均未达到3%改善：不继续增加N5/N6复杂度；
- N5不能优于N4：最终使用工艺残差，不保留`r_e`代理；
- N6只改善训练集或个别折：删除门控；
- A/B选择不稳定：使用通道对称表示；
- 改善来自少数样本、单一版本或单一工艺组合：判为未通过；
- 人工物理特征无增量但CNN残差有效：只说明波形包含当前代理未捕获的信息；
- Z向代理无增量：不得声称槽底法向振动是主要驱动。

## 6. 方案2：实测槽底几何与基准信号增强

### 6.1 目标和边界

方案2回答：

> 补齐槽底有效生成几何、传感器坐标与标定信息，并通过停机、空转和空走刀分离背景振动后，切削特有振动能否比方案1更稳定地解释槽底Ra残差？

方案2仍是增强物理代理与CNN-TCN残差模型，不扩展为必须依赖切削力系数、完整FRF、编码器相位和实测跳动的完整动力学模型。

### 6.2 必须补齐的信息

P0：

- 端刃有效圆角或过渡半径`r_e`；
- 若不存在可用`r_e`：端切削刃角、碟形角、端刃结构和刀具倾斜；
- `Ch9_g/Ch10_g`真实X/Y对应；
- 三轴正方向、传感器姿态和进给方向；
- CSV是否为标定后的`g`；
- 传感器型号、灵敏度、量程和有效频带；
- 粗糙度测针方向、评价长度和截止波长；
- 刀具实际悬伸量；
- 全槽铣`ae≈10 mm`的正式确认。

P1：

- 刀具端部清晰照片或显微图；
- 刀具批次、累计使用时间、换刀和积屑记录；
- 基准采集的刀具、刀柄、悬伸和冷却状态；
- 机床暖机时间和采集顺序。

无法提供编码器和跳动记录时：

- 使用名义转速；
- 不做严格阶次跟踪；
- 不分离真实逐齿跳动贡献；
- 不将主轴测点代理称为真实刀尖位移。

### 6.3 基准信号采集

共同条件：

- 同一传感器和安装位置；
- 同一25,600 Hz采样率；
- 同一采集卡和量程；
- 同一刀具、刀柄及悬伸；
- 一致的机床暖机状态；
- 保存连续时间轴和完整元数据。

停机：

- 主轴和进给轴停止；
- 每次60秒；
- 至少3次；
- 用于估计传感器、采集卡和环境噪声底。

主轴空转：

- 覆盖4000–8500 rpm，间隔500 rpm的10个转速；
- 每个转速30–60秒；
- 每个转速至少3次；
- 用于识别主轴转频、不平衡、轴承和结构背景。

相同NC路径空走刀：

- 无材料切削；
- 执行相同路径、转速和进给；
- 优先覆盖全部不同的`(n,fz,NC路径)`组合；
- 每个组合2–3次；
- 组合过多时至少覆盖参数空间边界、中心和全部正式验证转速；
- 用于识别伺服、导轨、路径和进给运动背景。

不同次采集不同步，禁止逐点时域相减。只能比较PSD、频带能量、dB比、SNR和条件背景特征。

### 6.4 基准质量门槛

- 无NaN、Inf、缺失通道、全零或明显削顶；
- 采样率和通道顺序与切削信号一致；
- 同条件主要频带能量变异系数原则上≤20%；
- 同条件重复PSD差异原则上约≤3 dB；
- 空转主要转频成分位于名义转频±2%范围；
- 空走刀路径、转速和进给设定一致；
- 文件记录转速、进给、路径、重复编号、采集时间和装夹状态。

不合格信号先人工复核。确认存在装夹变化、量程变化或采集故障时，不与其他基准合并。

### 6.5 槽底几何分支

存在有效圆角时：

\[
Ra_{geo,bottom}
=
\frac14
\left[
r_e-\sqrt{r_e^2-(f_z/2)^2}
\right]
\]

`r_e`作为实测刀具参数固定输入，不根据Ra表现选择。

无可用圆角时：

- 不令`r_e=0`；
- 不使用`fz²/(32r)`；
- 根据端切削刃角、碟形角、刀轴倾斜和端刃扫掠轨迹建立数值包络；
- 几何不完整时降级并报告不确定性。

### 6.6 背景校正物理量

估计：

\[
P_{stop}(f),\quad
P_{idle}(f\mid n),\quad
P_{air}(f\mid n,f_z,path)
\]

构造频带超额能量：

\[
E_{cut,excess}
=
\int_{\mathcal B}
\max[P_{cut}(f)-P_{air}(f),0]\,df
\]

构造dB能量比：

\[
R_{\mathcal B}
=
10\log_{10}
\frac{E_{cut,\mathcal B}+\epsilon}
{E_{air,\mathcal B}+\epsilon}
\]

重点输出：

- Z向带限位移代理及背景校正量；
- Z向TPF及倍频超额能量；
- Z向高频冲击超额能量；
- 真实进给轴和横向轴超额能量；
- 停机、空转、空走刀条件下的SNR；
- 切削特有谱峰和背景共有谱峰。

增强物理基线：

\[
Ra_{bottom,physical,cal}
=
b_0+b_1Ra_{geo,bottom}
+b_2D_{Z,excess}
+b_3E_{Z,TPF,excess}
+b_4E_{Z,HF,excess}
\]

所有系数只在当前训练折拟合，不预设Z向振动一定增加或降低Ra。

### 6.7 基准匹配

每个切削片段匹配：

```text
同批次停机
+ 同转速空转
+ 同转速、同进给、同NC路径空走刀
```

- 空转优先精确匹配转速；
- 单个中间转速缺失时，可在相邻转速间做频谱统计插值，并增加缺失标记；
- 空走刀不得跨路径直接替代；
- 正式确认性分析要求全部测试片段有合格匹配基准；
- 匹配过程不得使用Ra标签。

### 6.10 方案2确认性验收

参考模型：

\[
B_{ref}
=
\min
\left(
MAE_{quadratic},
MAE_{方案1最佳}
\right)
\]

最终模型必须同时满足：

1. 相对`B_ref`的组均衡加权MAE改善≥5%；
2. 至少4/5外层折改善；
3. 三个随机种子分别均改善；
4. 组级配对Bootstrap 95%置信区间排除无改善；
5. 相对相同网络但不使用新几何和基准信号的版本，MAE进一步改善≥2%；
6. 改善不集中在单一版本、单一转速或少数异常组；
7. RMSE和R²方向不与MAE结论明显冲突。

物理贡献：

- 槽底几何校准系数至少4/5折保持合理正方向；
- P5相对P2改善≥2%或显著降低折间波动；
- N5优于普通拼接版本；
- N6只有进一步改善且不增加明显方差时保留。

### 6.11 方案2停止与降级

- `r_e`或端刃几何无法可靠确认：不启动方案2；
- 传感器单位或有效频带无法确认：不输出微米单位位移代理；
- 基准重复性不合格：重新采集；
- 空走刀无法匹配正式路径：降级为停机＋空转版本并明确缺项；
- P5不能优于P2：停止复杂化背景校正；
- N5不能优于B1：结论为补充物理信息未带来稳定预测增量；
- N6不能优于N5：删除门控；
- 最终未达确认性标准：仅保留机制分析，不宣称提高预测性能。

## 8. 方案选择口令

后续执行边界固定如下：

- 用户明确说“推进方案1”：只使用现有数据，实施第5节及共同底座，不要求补实验。
- 用户明确说“推进方案2”：先核对第6.2至6.4节的信息和基准数据是否齐备，通过后实施第6节。
- 用户未明确方案编号：只进行必要的只读分析或澄清，不启动训练和新增模型实现。

## 9. 设计边界

- 两套方案共享工程，不建立两份相互漂移的代码；
- 方案2是方案1的可追踪增强，不改变固定外层折；
- 不因结果不理想修改测试折；
- 不把未知`r_e`、预测偏好的X/Y映射或主轴测点位移代理写成实测事实；
- 不把完整动力学模型所需的FRF、切削力系数、编码器和跳动参数默认为已知；
- 任何模型复杂度增加都必须通过同折消融证明其增量。
