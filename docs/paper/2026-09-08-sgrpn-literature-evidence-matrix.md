## Search and verification boundary

The bounded search covered six themes: process-parameter roughness baselines; vibration, force, current, and heterogeneous sensor fusion; learned gating and fusion negative transfer; manufacturing prediction intervals; conformal prediction; and hierarchical/grouped conformal inference. Preference was given to publisher records, DOI landing pages, journal-hosted full text, institutional publication records, and arXiv only where it was the canonical public record. Review articles were used to support field-level categorization, whereas method and result statements were tied to primary papers.

This matrix is a claim-control device, not a bibliometric proof of exhaustive coverage. “No paper in the verified set jointly addresses X” is permitted only as a bounded observation. It must not be rewritten as “no prior study has addressed X.”

## Claim controls derived from the evidence

| Proposed statement | Status | Required wording |
| --- | --- | --- |
| Recent roughness studies use process variables, monitored signals, and multi-source deep fusion. | Supported | Cite representative studies and avoid implying exhaustiveness. |
| Sensor fusion always improves roughness prediction. | Rejected | Say that benefits are dataset- and validation-dependent; test group-wise harm explicitly. |
| Existing roughness research ignores uncertainty. | Rejected | Cite R8 and R9 as direct counterexamples. |
| This is the first use of conformal prediction for roughness. | Rejected | R9 is a direct counterexample available before the search cutoff. |
| A gate is a probability of physical sensor reliability. | Rejected | Describe it only as a bounded learned correction coefficient. |
| Ordinary i.i.d. conformal calibration automatically handles grouped readings. | Rejected | Tie the calibration score and exchangeability assumption to machining groups, citing R12–R14. |
| Group conformal solves arbitrary changes in material, machine, or process. | Rejected | Limit the statement to exchangeable new groups of the observed experimental type. |
| No prior work jointly solves the exact SGRPN combination. | Use only as a bounded positioning statement | Say that no single paper in the verified set jointly addressed all four specified requirements; do not claim universal absence or priority. |

## Positioning sentence approved for the manuscript

> Existing studies separately establish the value of process baselines, monitored-signal fusion, prediction intervals, and conformal calibration. The present contribution is their group-aware, failure-conscious synthesis for a weak-increment vibration setting: an explicit process fallback, group-level negative-transfer evaluation, end-to-end group isolation, and simultaneous coverage of the regions and repeats in an exchangeable new machining group.
